# 小红书笔记草稿

## 标题

给 Codex 做了一个 macOS 顶部状态栏余量小组件

## 正文

最近一直在用 Codex，最想看的其实不是复杂报表，而是顶部状态栏里随手扫一眼：当前 5 小时额度和周额度还剩多少。

于是做了一个极简 macOS 菜单栏小工具：CodexUsageBar。

它现在只做几件事：

- 顶部状态栏显示：`h89 w32`
- 点击后能看到完整 Usage：5 小时 / 1 周
- 支持手动刷新
- 可以一键打开官方 Usage 页面
- 没有通知、趋势图、数据库、预算统计这些复杂功能

这版先用 Mock 数据把 UI 和交互跑通，真实数据源只会等官方可读接口、CLI 输出或官方本地状态可用后再接。

边界也写清楚了：不抓浏览器 Cookie，不读取浏览器数据库，不模拟登录，不上传任何用户数据。

适合和我一样只想在菜单栏看一眼余量的人。
